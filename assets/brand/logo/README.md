## 配色与底色约束（实测结论，务必遵守）

本 Logo 具有**分裂性格**，两类元素对底色的要求相反：

| 元素 | 实测色 | vs 深色底 `#14181d` | vs 暖灰底 `#e9e4de` | 结论 |
|---|---|---|---|---|
| 字标「panomint」 | `rgb(4,33,59)` 深墨 | **1.09:1 不可见** | **12.92:1 优秀** | 字标**必须**浅底 |
| 胶片盘主体 | `rgb(57,156,209)` 青 | 5.81:1 良好 | 2.43:1 偏弱 | 盘面**宜**深底 |

由此得出的硬约束：

1. **全标记版（盘面 + 字标）只能放在浅色底上**（`#e9e4de` 暖灰底实测最优）
2. **深色页（`#14181d`）只能用盘面裁切版**，或干脆不放 Logo —— 见设计规格 §3.4
3. PWA `maskable` 图标底色必须补纯色底（源图为透明底），且**圆角归 0**（系统按 mask 裁，预置圆角会被二次裁切产生瑕疵）
4. 内容直径实测占边长 69.3%，**天然满足 80% 安全区**，无需缩小标记

## 像素实测基线（供切图复用）

- 标记内容框：`[169,251] → [831,801]`，即 663×551，**仅占画布 64.6% × 53.8%** —— 直接当图标用会显得很小，需按安全区放大
- 盘面裁切框：`[295,251] → [705,660]`，即 411×410，**aspect ≈ 1.002，天然方形**，适合做 favicon
- 整体平均饱和度 0.58，是全站唯一高饱和元素（莫兰迪体系饱和度封顶 0.25）

### 🔴 盘面裁切框四边余量为 0（实测，勿再假设它有留白）

```
盘面版不透明区 = x 295..704, y 251..659   （与裁切框完全重合）
四边余量 L0 T0 R0 B0
四角 alpha：左上=0  右上=0  左下=255  右下=255
```

即**盘面 artwork 铺满裁切框**，且上下角透明度不一致（下角不透明）。
因此「盘面资产四角 alpha 必须为 0」这一断言**在物理上不可能满足** ——
若照此断言写测试，会得到一个永不通过的永久红灯，反而掩盖真问题。
`prepare_brand_web_assets.py` 的正确断言是「mode==RGBA 且**含真透明像素**」，不是「四角 alpha==0」。

推论：盘面版缩到 64×64 / 32×32 时，图案是**内接于画布且四边被触及**，
favicon 场景无问题（系统会按 mask 裁切），但若将来用作需要留白的 inline 图标，须自行补padding。

如未来需要完全无残留的矢量版，建议重新生成源图时要求「纯色背景 / 透明背景」。

## 已知限制（如实记录）

本资产是 **3D 渲染风格的位图**，不是矢量图，因此：

1. **不可无限缩放** —— 印刷场景（如包装、超过 300dpi 的画布）会糊，源图 1024px 是上限
2. **没有单色/反白版本** —— 位图无法像矢量那样一键改色，做 favicon 需另备
3. **深色底表现较差** —— 3D 高光与深色对比强烈，浅色底上更干净
4. **文件偏大** —— 1024 透明版约 940KB；web 场景建议用 256 版（53KB）

如需矢量版（SVG/PDF），建议以本图稿为参考重绘，而不是对位图做自动描摹
（自动描摹对 3D 高光与渐变会产生大量碎路径，体积反而更大且失真）。
