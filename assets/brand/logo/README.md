# Panomint 正式 Logo 资产

## 来源与处理记录（请保留）

| 项 | 内容 |
|---|---|
| 原始来源 | AI 生成图像（豆包 / Doubao），1024×1024 RGB |
| 生成标识 | 原图右下角含「豆包AI生成」水印 |
| 处理 1 | **移除生成标识** —— 定位 x=841..1001 y=968..1004 的 1625 个水印暗像素，从同高度水平镜像干净区克隆覆盖 + 7px 羽化混合。处理后该区域暗像素 = **0** |
| 处理 2 | 制作真透明底版 —— 原图「棋盘格」是**烤进像素的近白底纹（242~255）不是真透明**，故无法裁切+补边解决 |
| 工具 | `scripts/prepare_logo_asset.py`（Pillow，纯本地处理） |

**处理后仍可能残留**：0.87% 的近白像素被判定为「图形内高光」而保留不透明。
在浅色底上不可见；在深色底上可见极轻微的浅斑。这是**字标本身为白色**导致的
固有约束 —— 白色字标与近白背景在颜色上无法区分，只能靠几何/连通性分离，
激进阈值会打穿字母（实测阈值 800 会打穿，1200 安全）。

如未来需要完全无残留的矢量版，建议重新生成源图时要求「纯色背景 / 透明背景」。

## 已知限制（如实记录）

本资产是 **3D 渲染风格的位图**，不是矢量图，因此：

1. **不可无限缩放** —— 印刷场景（如包装、超过 300dpi 的画布）会糊，源图 1024px 是上限
2. **没有单色/反白版本** —— 位图无法像矢量那样一键改色，做 favicon 需另备
3. **深色底表现较差** —— 3D 高光与深色对比强烈，浅色底上更干净
4. **文件偏大** —— 1024 透明版约 940KB；web 场景建议用 256 版（53KB）

如需矢量版（SVG/PDF），建议以本图稿为参考重绘，而不是对位图做自动描摹
（自动描摹对 3D 高光与渐变会产生大量碎路径，体积反而更大且失真）。
