## 1. 快速认知

### 1.1 这是什么

Panomint（全景相册）是一套自托管的照片与视频管理系统，目标是替代群晖 Photos 一类闭源相册：照片视频集中存放、按时间轴浏览、全屏地图、AI 语义搜索、人脸识别分组、相册分享。它跑在你自己的服务器或 NAS 上，数据不出你的设备。

特色能力一览：

| 能力 | 说明 |
| --- | --- |
| 时间轴 | 按拍摄时间倒序浏览全部媒体，支持缩放、按媒体类型过滤、悬停即时预览 |
| 全景播放 | 360° 照片/视频支持拖动、手机陀螺仪、VR 头显 |
| 流媒体 | 视频自动转码为多档 HLS，弱网自动降档，拖动即时起播 |
| 全屏地图 | 带 GPS 的媒体在地图上聚合展示，与时间轴双向联动 |
| AI 搜索 | 输入中文描述（如「海边的狗」）找图，无需人工打标签 |
| 人物 | 自动检测人脸并按人分组，可手工合并/确认 |
| 相册 | 手工相册 + 条件相册（按时间/地点/类型自动收录） |
| 分享 | 生成免登录链接，微信里自动出卡片，访客可打包下载 |
| 多用户 | 角色与权限体系，适合家庭/小团队共用 |

### 1.2 界面总览

登录后左侧是主导航：

| 菜单 | 作用 |
| --- | --- |
| 时间轴 | 全部照片视频的主浏览页（默认首页） |
| 地图 | 全屏地图模式 |
| 相册 | 手工/条件相册的创建与浏览 |
| 人物 | 人脸分组 |
| 地点 | 按城市/区域归纳的媒体列表 |
| 标签 | 手工标签与 AI 建议标签 |
| 空间 | 个人空间/团队空间的入口 |
| 文件夹 | 按目录结构浏览（对应磁盘上的真实目录） |
| 工具箱 | 重复项目、最近删除、已恢复、扫描导入（需管理员先分配扫描根目录） |
| 设置 | 账号安全与偏好 |
| 管理 | 仅管理员可见：用户/角色/权限/任务/审计/地图配置/存储 |

顶部工具栏常驻「上传」按钮，任何页面一键进入上传。

### 1.3 基本概念

- **媒体**：单张照片或单个视频，系统的最小单位。
- **空间**：媒体的归属范围。个人空间只有本人可见；团队空间可按角色授权。
- **相册**：媒体的集合，分手工相册（手动增删）与条件相册（设好规则自动收录）。
- **文件夹**：磁盘真实目录的映射，删除文件夹内容会真实删文件，请谨慎。
- **人物/标签/地点**：三种自动或半自动的组织方式，均可手工修正。

## 2. 安装（三种形态任选其一）

三种形态任选一个即可，不要混装。共用前提：x86_64 的 Linux 服务器（或支持 Docker 的 NAS），至少 2 核 CPU / 4GB 内存 / 20GB 磁盘（媒体另算）。

| 形态 | 适合谁 | 特点 |
| --- | --- | --- |
| Docker 镜像版 | 大多数用户 | 一条 compose 起全套，隔离干净，升级最简单 |
| 集成包（免 root） | 虚拟主机/无 root 权限/面板用户 | 单个目录自包含，不碰系统，自带全部依赖 |
| 裸机一键脚本 | 有独立服务器、追求性能 |  systemd 托管、依赖装进系统，开机自启 |

### 2.1 Docker 镜像版（推荐）

```bash
# 1. 解压发布包后进入 docker 目录
cp .env.example .env
# 2. 编辑 .env，至少填两项（值用 openssl rand -base64 32 之类生成强随机值）：
#    POSTGRES_PASSWORD=...
#    JWT_SECRET=...
# 3. 启动
docker compose up -d
# 4. 看日志确认启动完成（api 首次启动会自动建表，属正常现象）
docker compose logs -f api
```

启动完成后浏览器访问 `http://服务器IP:8088`，进入第 3 章的初始化向导。

可选：`docker compose --profile workers up -d` 额外起索引/转码/AI 后台进程（默认 release compose 已含基础进程；workers 画像按需开启，详见 `release/docker/README.md`）。

### 2.2 集成包（免 root）

把 `panomint-1.0.0-linux-amd64-bundle.tar.gz` 上传到服务器，解压到你想安装的目录（如 `~/panomint`）：

```bash
tar xzf panomint-1.0.0-linux-amd64-bundle.tar.gz
cd panomint-1.0.0
./bundle/install.sh      # 交互式：会问数据库地址、端口、密钥等
```

`install.sh` 会生成 `.env` 和数据目录、跑数据库初始化。日常用 `panoctl` 管理：

```bash
./bundle/panoctl env-check    # 启动前体检：缺什么依赖会直接告诉你
./bundle/panoctl start        # 启动全部 8 个进程
./bundle/panoctl status       # 看每个进程状态
./bundle/panoctl logs api     # 跟踪 api 日志
./bundle/panoctl stop         # 全部停止
```

前置依赖（脚本会逐项核验，缺的会明确报错）：PostgreSQL 16+（带 PostGIS、pgvector 扩展）、Valkey（或 Redis 兼容服务）、ffmpeg。数据库可以是本机也可以是另一台机器。

### 2.3 裸机一键脚本（Debian / Ubuntu，需 root）

```bash
tar xzf panomint-1.0.0-linux-amd64-baremetal.tar.gz
sudo bash panomint-1.0.0/baremetal/install.sh
```

脚本自动完成：装 PostgreSQL 16 + PostGIS + pgvector + Valkey + ffmpeg（走 PGDG 官方源）、建库建账号、生成密钥、落盘程序、注册 systemd 服务并启动 7 个服务。装完会打印访问地址和下一步指引。仅支持 Debian 12 / Ubuntu 22.04 及以上。

### 2.4 安装后检查

三种形态通用：

1. 浏览器访问站点，应看到初始化向导（首次）或登录页。
2. `curl http://服务器IP:8088/version` 应返回 JSON 版本信息（如 `{"version":"1.0.0",...}`）——返回 HTML 说明反代/端口不对。
3. Docker 形态 `docker compose ps` 全部 `running` / `healthy`。

## 3. 首次初始化向导

首次访问时，系统会强制进入一次性初始化向导（此后不再出现）：

1. 设置管理员邮箱（作为登录账号）。
2. 设置显示名称（可后改）。
3. 设置密码（至少 8 位，建议 12 位以上并混排字母数字符号）。
4. 二次确认密码后提交。

提交成功后自动跳到登录页，用刚创建的账号登录即可。**这个账号是唯一的管理员（owner）**，后续可在管理后台创建其他用户并分配角色。

要点：

- 向导以「系统里是否已有任何账号」为判据：只要创建了第一个账号（哪怕后来删除），向导就不再出现。
- 如果多人同时装，只有第一个提交者成功，后来者会看到「系统已完成初始化」提示——这是正常的防重入保护。
- 向导页会显示当前版本号，与 `curl /version` 一致，可作为「装的是不是预期版本」的第一现场核验。

## 4. 登录与账号安全

### 4.1 登录

邮箱 + 密码登录。登录态默认保持一段时间，过期后自动回登录页。公共设备上请用完后主动退出。

### 4.2 二次验证（TOTP）

设置 → 二次验证：

1. 用手机装任意 TOTP 应用（如 Aegis、Google Authenticator、1Password）。
2. 扫页面上的二维码，输入应用显示的 6 位验证码确认开启。
3. 务必保存页面给出的恢复码（建议打印或抄在密码管理器里）。

开启后，每次登录除密码外还要填 6 位动态码。手机丢失时用恢复码解除。恢复码用一次即失效。

### 4.3 修改密码

设置 → 修改密码：输入当前密码 + 两次新密码（至少 8 位）。修改成功后其他设备的登录态会被踢出，需重新登录。

### 4.4 应用密码（第三方客户端）

设置 → 应用密码：为不支持动态码的客户端（如同步工具、WebDAV 挂载）签发专用密码。每个应用密码只显示一次，请立即抄走；泄露或不用了可在列表里吊销。**应用密码和你的主密码相互独立，吊销它不影响主密码。**

### 4.5 忘记密码

联系管理员。管理员在 管理 → 用户 里选中你的账号 → 重置密码，设一个新密码后告知你；你登录后应立即在设置里改掉。

## 5. 日常使用

### 5.1 上传

入口：顶部工具栏「上传」、时间轴页的上传入口、或直接访问 `/upload`。支持批量选择，断点续传（分块上传），单文件上限默认 100MB（部署时可调）。上传完成后系统自动：

- 提取拍摄时间、GPS、相机参数；
- 生成三档缩略图（WebP）；
- 识别 360° 全景媒体；
- 视频进入转码队列（多档 HLS）；
- 进入 AI 索引队列（向量、标签建议、人脸检测，后台异步完成，无需等待）。

大文件转码耗时取决于服务器性能，期间媒体以原片预览，转码完成后自动切换为多档流。

### 5.2 时间轴

默认首页，按拍摄时间倒序平铺全部媒体：

- **缩放**：底部/侧栏滑块调节时间粒度（年→月→日）。
- **过滤**：按类型（照片/视频/全景）与所在空间过滤。
- **悬停预览**：鼠标悬停或长按出现即时预览窗，可翻页快速浏览。
- **选择**：单击选中一张；右上角有 全选/反选；选后可批量移动到相册、加标签、下载、删除。
- **地点栏**：顶部横向滑动条按城市归纳，点选即过滤。

### 5.3 播放

点击进入播放页：

- 普通照片：缩放、适应窗口、查看 EXIF。
- 全景照片/视频：拖动环视；手机上点「陀螺仪」图标后随手机转动视角；支持 VR 头显（WebXR）。
- 视频：默认自适应多档 HLS；播放栏可手动选档；分享页同样生效。

### 5.4 相册

相册页 → 新建相册：

- **手工相册**：创建后从时间轴选图「移动到/复制到」相册，或进相册详情添加。
- **条件相册**：设定规则（时间段、媒体类型、地点范围、标签等），符合条件的媒体自动收录，规则可随时改。

相册详情页支持排序、封面设置、评论（如管理员开启）、生成分享链接。

### 5.5 空间与文件夹

- **空间**：个人空间（仅自己）与团队空间（按角色可见）。上传时可选落入哪个空间。
- **文件夹**：对应磁盘真实目录。左侧选目录右侧出图；支持层级返回导航。注意：文件夹里的删除是**真删文件**，与相册移除（只去引用）不同。

### 5.6 地图与地点

- **地图页**：全屏地图，带 GPS 的媒体按位置聚合成簇，缩放自动散开；点击标记弹出预览，可与时间轴双向联动（地图上选中时间段，时间轴同步过滤）。
- **地点页**：按行政区划（省/市）自动归纳媒体，横向卡片浏览，点进即该地全部照片。

国内部署默认使用高德瓦片（管理后台可换其他源或自备瓦片服务）。

### 5.7 搜索

顶部搜索框，两种模式：

- **全文搜索**：匹配文件名、标签、地点、EXIF 等文本（支持拼音与模糊匹配）。
- **语义搜索**：直接用自然语言描述画面（如「去年秋天公园的红叶」），靠 AI 向量匹配，不需要事先打任何标签。

### 5.8 标签

标签页管理全部标签：手工打的标签、AI 建议的标签（导入前逐条确认）。给媒体打标签：时间轴选中 → 加标签；或在媒体详情页操作。AI 建议标签在后台自动生成，进标签页「待确认」列表批量接受或忽略。

### 5.9 人物

人物页展示系统自动检出的人脸分组：

- 自动分组按相似度聚合，同一人可能被分成多组。
- 点进一个人物组：可改名、合并到另一个人物组、逐张确认/移出。
- 默认参数：检测置信度 0.87、最小人脸 24 像素、合并阈值 0.40（管理后台可调，调后对新扫描生效）。

人脸特征以 128 维向量存储，仅用于本地相似度比对，不上传任何外部服务。

### 5.10 工具箱

工具箱四个页签：

- **重复项目**：按感知哈希找出的疑似重复照片，可比对后删除冗余（保留最高清的一份）。
- **最近删除**：删除的媒体先进这里（软删除），保留期内在可恢复；彻底清空才真正删除。
- **已恢复**：恢复操作的留痕列表。
- **扫描导入**：把服务器磁盘上你权限范围内的照片/视频导入自己的库（详见 8.4 末「成员自助扫描」）。**需要管理员先在管理后台为你分配「扫描根目录」**，未分配时页签内会显示引导提示，无法发起扫描。

## 6. 分享

相册或媒体的分享：在相册详情页「生成分享链接」，系统产出免登录链接。把链接发给任何人即可查看；微信里转发会自动带标题卡片和封面图。

分享管理（侧栏进入分享列表或相册详情）：

- 随时**作废**链接，作废后立即失效。
- 可开启**允许下载**，访客可单张或打包（ZIP）下载原图。
- 查看访问统计（如部署开启了审计）。

注意事项：分享链接等同于钥匙，只发可信的人；链接泄露请立即作废重建。

## 8. 管理后台

左侧「管理」入口（仅 admin:users / admin:system 权限角色可见）。九个页签：

| 页签 | 用途 |
| --- | --- |
| 概览 | 用户数、媒体量、存储占用、系统状态速览 |
| 用户 | 创建/停用/删除用户、重置密码、**分配扫描根目录**（决定该账号在「工具箱 → 扫描导入」可扫描的物理范围，未分配则无扫描权限） |
| 角色 | 定义角色（owner/admin/member/自定义） |
| 权限 | 权限点清单与说明（如 media:read、share:create） |
| 任务 | 后台任务队列（转码/索引/AI）状态与失败重试 |
| 审计 | 登录、权限变更、分享、删除等关键操作留痕 |
| 地图配置 | 瓦片源、地理编码服务配置 |
| 存储 | 扫描导入、网络挂载（SMB/NFS/WebDAV 经 rclone 接入，导入落点为可浏览的语义目录）、挂载探活 |
| 转码 | 系统级「自动 HLS 转码」开关（默认开）：关闭后全站视频不再转码、播放直接用原始文件，缩略图与语义索引照常生成，避免大视频转码长时间占满服务器；360° 视频依赖 HLS 切片，关闭后新 360 视频将无法播放 |

### 8.1 用户与角色

预置角色：owner（全部权限）、admin（管理权限）、member（普通成员）。自定义角色 = 勾选权限点组合；权限点遵循最小授予原则，**任何人只能授予自己已拥有的权限**（系统强制，防止提权）。

**分配扫描根目录**（用户页签「分配扫描根」列）：为普通账号指定其可扫描的物理目录——可以是整个媒体根，也可以是媒体根下的某个子目录（必须是真实存在的物理目录）。分配后该账号在「工具箱 → 扫描导入」里自助扫描入库，导入的媒体归属其本人；可随时改派或清除（清除后该账号立即失去扫描入口，进行中的扫描即时失败）。系统保留目录 `_imports` 不可分配，成员越权访问根目录之外的文件会被服务端拒绝。

### 8.2 网络挂载

存储 → 挂载：把另一台 NAS/服务器的目录经 SMB/NFS/WebDAV 挂进系统。挂载后像本地目录一样浏览、纳入索引。断连时界面即时提示，恢复后自动重连（探活机制）。凭据只存服务端，不明文展示。

### 8.3 审计

审计页记录：登录成功/失败、二次验证变更、密码重置、分享创建/访问、删除与恢复、权限调整、初始化完成等。支持按操作人/动作/时间筛选，可用于事后追溯。**审计记录只增不删**，请勿当作可清理项。

### 8.4 扫描导入（把已就位媒体入库）

存储 → 扫描导入：媒体文件已放进媒体库目录（含网络挂载导入的目录）但系统还没识别时，用扫描把它们入库。两种方式任选、可自由切换互不冲突：

1. **目录树选择（推荐）**：点输入框右侧「浏览…」，弹出目录树对话框，逐级展开点选目标目录——无权限的目录以锁定图标标示、不可展开；空目录会明确显示「（无子目录）」；层级再深也是点一层加载一层，不卡界面。选中后点「选择此目录」，路径自动填回输入框并**自动开始扫描**。
2. **手动输入**：直接在输入框键入相对媒体根的路径（留空 = 扫描整个媒体根），点「开始扫描」。

扫描异步执行，进度条实时显示处理/总数，完成后导入的媒体归属当前登录账号（哈希去重，重复扫描不重复占用存储）。

**成员自助扫描**（v1.12 起）：管理员在「用户」页签为某账号分配扫描根目录后，该账号左侧「工具箱」会出现「扫描导入」页签——在分配的范围内用同样的目录树选择器选子目录扫描，入库归属成员本人。未分配的账号页签内显示引导提示、无法发起扫描；成员的越界请求由服务端钳制（不是前端隐藏）。

## 9. 维护与升级

### 9.1 备份

需要备份的清单（Docker 形态对应卷）：

| 内容 | 位置 |
| --- | --- |
| 数据库（元数据、用户、标签、人脸向量） | PostgreSQL 数据目录 / `pgdata` 卷 |
| 原始媒体 | MEDIA_ROOT / `mediadata` 卷 |
| 转码产物（可重建，但重建耗时） | HLS 输出目录 |
| 配置 | `.env`、compose 文件 |

建议：数据库每日 `pg_dump` + 媒体目录定期快照。`mediadata` 卷务必纳入备份（历史事故教训：卷误删导致媒体灭失且无法重建）。

### 9.2 升级

原则：同大版本（1.x）滚动升级，跨大版本（2.0）看迁移指引。通用步骤：

1. 备份（9.1）。
2. 取新版本发布包。
3. Docker：`docker compose pull && docker compose up -d`（api 启动自动跑增量迁移，幂等，失败会拒绝启动并打日志）。
4. 集成包：`./panoctl stop` → 替换二进制与前端目录 → `./panoctl start`。
5. 裸机：systemd `stop` → 替换 `/opt/panomint` 下文件 → `start`。
6. 验证：`/version` 显示新版本、`/ready` 就绪、抽查时间轴与播放。

### 9.3 日志

| 形态 | 位置 |
| --- | --- |
| Docker | `docker compose logs -f api`（worker 同理） |
| 集成包 | `./panoctl logs api` / 安装目录 `logs/` |
| 裸机 | `journalctl -u pano-api -f` |

### 9.4 健康自检

- `/health`：进程存活。
- `/ready`：磁盘/数据库/缓存全连通。
- 管理 → 任务：看后台队列有无积压或死信。

## 10. 常见问题与排障

**Q1 打开网站一片空白 / 一直转圈？**
先按顺序查：1) `curl http://IP:8088/version` 是否返回 JSON——返回 HTML 是端口/反代问题；2) Docker 形态 `docker compose ps` 是否全部 running；3) 浏览器 F12 看 Console 报错，接口 401 是登录态过期，重新登录。

**Q2 忘记管理员密码且没有第二个管理员？**
用部署机直接连数据库删除该用户行后重启（会回到「未初始化」状态，向导重新出现，可重建管理员）；或从数据库层面用 bcrypt 工具生成新哈希替换。操作前务必备份数据库。

**Q3 上传卡住或失败？**
单文件默认上限 100MB（nginx client_max_body_size），超限改部署配置；局域网 http 环境请确认网络稳定；失败的任务会在上传页给出重试入口。

**Q4 视频一直在转圈不能播？**
转码是后台异步任务：管理 → 任务 看转码队列状态；cpu 软编较慢属正常（数分钟量级）。任务失败会有死信记录，可重试。

**Q5 地图不显示 / 灰底？**
检查管理 → 地图配置的瓦片源；国内服务器确认高德 key 有效；内网无外网时需自备瓦片服务。

**Q6 搜不到刚上传的图？**
AI 向量索引是后台队列，刚传完可能还没索引到；等管理 → 任务 里 embed 任务清零再搜。全文搜索（标签/文件名）是即时的。

**Q7 微信里打开分享链接是白页？**
微信内置浏览器兼容：链接会自动处理 OG 跳转；确保分享未作废、网络可达；仍异常时换系统浏览器打开同一链接对照。

**Q8 如何彻底删掉某张照片？**
时间轴选中删除（进最近删除）→ 工具箱 → 最近删除 → 彻底清空。注意文件夹视图里的删除是直接删文件，没有回收站。

**Q9 空间满了 / 磁盘告警？**
管理 → 概览 看占用；清理顺序建议：最近删除清空 → 重复项目清理 → 低价值原始视频（确认已备份后）。媒体与数据库分盘部署时两边都要看。

**Q10 版本号显示 dev？**
开发/手工构建的产物默认显示 `dev`；正式发布的构建（发布包/发布镜像）会注入真实版本号。看到 `dev` 说明跑的是非发布构建，不影响功能，升级时按 9.2 换正式包即可。

**Q11 工具箱「扫描导入」提示未分配扫描根？**
这是管理员未给你的账号分配扫描根目录。联系管理员在「管理后台 → 用户」页签点「分配扫描根」即可；分配后刷新立即可用。
