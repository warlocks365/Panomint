## 一、更新摘要

v1.7.0 补齐「账号与安全」管理面：管理员此前只能建号、删号，既管不住弱密码、也管不住暴力试错——重置密码只能明文传达、注册入口完全缺失、HTTP/HTTPS 端口写死 80/443。本版本将注册、密码强度、登录锁定三组策略集中为管理后台「账号策略」页签（第十一页签），重置密码改为一次性临时密码并强制改密闭环，访问端口可配置且重定向目标随端口生效。

### 1.1 新增与改动

| 模块 | 内容 |
| --- | --- |
| 账号策略页签 | 管理后台新增第十一页签：注册开关与邀请码、密码强度要求、登录失败锁定策略三组配置集中管理（手册 §8.8） |
| 账号自助注册 | 注册默认**关闭**；开启后需凭一次性邀请码注册，邀请码用后即废、可设过期时间（手册 §4.6） |
| 登录失败锁定 | 连续输错密码达上限（默认 5 次）锁定 15 分钟；中途一次正确登录清零计数；登录接口返回 423 与剩余锁定分钟数 |
| 密码强度策略 | 最低长度（8–64，默认 8）与字符类别要求（大写/小写/数字/特殊字符可勾选），注册、改密、重置全链路生效 |
| 重置密码闭环 | 管理员重置密码生成一次性临时密码——弹窗仅显示一次，持有者下次登录强制修改（手册 §4.5/§8.1） |
| 停用即下线 | 禁用账号立即失效其全部会话；用户列表直接展示各账号锁定与强制改密状态 |
| 访问端口配置 | HTTP 端口（默认 80）/ HTTPS 端口（默认 443）可配置，HTTP→HTTPS 重定向目标按 HTTPS 端口拼接（非 443 带 `:端口`），保存热生效（手册 §8.7） |
| 注销数据清理 | 用户注销触发其名下数据清理流程 |
| 权限防越权 | 改权限链路加固，杜绝低权账号自我提权 |

### 1.2 兼容性与质量

## 三、升级注意事项

1. **从 1.6.x 升级**：拉取 `:1.7.0`（或 `:latest`）镜像重建 web 与 app 容器即可；**本版含数据库迁移 00043**，由 api 容器启动自动执行，无需手工 SQL。api + 常驻 worker（embed/tag/faces/phash）共用 app 镜像，需一并 recreate；index/transcode worker 镜像独立，本版未变更可不重建。
2. **注册默认关闭**：升级后注册入口保持关闭（安全默认值）；如需开放自助注册，管理员在「账号策略」页签开启并发放邀请码。
3. **存量密码不受影响**：密码强度策略只约束新设/重置的密码，存量用户无需改密；强制改密仅对管理员重置过的账号触发。
4. **端口配置**：升级后 HTTP/HTTPS 端口默认 80/443，与既有部署行为一致；如需自定义在「网络」页签修改，热生效无需重启。
5. **降级回滚**：回滚到 1.6.0 仅需把 image tag 换回 `1.6.0` 重建；迁移 00043 新增的列与表对旧版代码无害（旧版不读取），无需回滚数据库。
