VIEW.22 · 播放器字幕显示 · 普通视频（原生 track）与全景视频（自研覆盖层）对照

PLAYER

字幕显示

两类播放器的实现路径完全不同，这是本功能最大的技术差异点
A · 普通视频 — 浏览器原生 <track>

直接使用 <track kind="subtitles">，语言切换 = 切轨，由浏览器渲染。 工程量小（约 0.5 天）；字幕样式受浏览器控制（可有限定制）。 单语显示；浏览器会记住上次选择的语言。
B · 全景视频 — 自研 DOM 覆盖层（原生 track 不生效）

01:12/ 05:41

视频是 WebGL 球面纹理，<track> 完全不生效。需自研：解析 VTT → 按 currentTime 渲染 DOM 覆盖层 → 提供「位置 / 字号 / 背景条」三个开关。 工程量 2 天，且需逐设备验证（桌面 + 手机陀螺仪 + VR）。

全景字幕的三个开关（建议新增，T-8）：① 位置 —— 底部居中 / 跟随视角（抬头时字幕仍可见）/ 可拖拽； ② 字号 —— 三档，VR 或远距离观看需要更大字号；③ 背景条 —— 默认开，避免雪景、天空等浅色画面上白字不可读。 这三项写入用户偏好（ui-prefs，注意整行替换语义：必须先读全量再合并写回）。
