视频字幕（语音识别）

已启用

对相册视频做本机语音识别，生成外挂字幕文件（SRT / VTT，可导出、可替换、可编辑）； 可选生成多语言翻译轨；字幕内容可参与全局搜索。 音频不出本机，识别过程不消耗外部额度。

模型文件不进镜像，首次启用时下载（支持镜像源）或手动放置到模型目录。 CPU 部署建议 small；有 GPU 时建议 large-v3-turbo-q5_0（质量与速度更平衡）。
识别语言
源语言
自动检测覆盖 whisper 支持的 99 种语言；检测结果写入字幕轨记录，用于展示与搜索过滤。
翻译轨（多语言）
＋ 更多语言
默认只生成原文轨；勾选的语言才会额外生成翻译轨。 翻译经「Agent 语义接口 · LLM 上游」进行，按 token 计费 —— 每多一种语言，费用约等于全片文字量的 2 倍 （输入 + 输出）。单日翻译句数上限见下。
触发方式
闲时段与「视频热点回忆」共用同一时段配置（当前 02:00–06:00）， 两个功能不会各配一套互相抢资源。「新视频自动」默认关闭 —— 批量导入会形成任务风暴。

设计说明
· 默认只出原文轨：识别是本机免费的，翻译是要花 token 的 —— 两者成本模型完全不同，所以默认值也不同
· 推理设备与「人脸识别 / 向量编码」同构（CPU / CUDA / 自动），GPU 不是前置条件
· 模型文件 466 MB–1.6 GB，不进镜像、不进 git， 走下载或挂载卷 —— 否则仓库与镜像都要膨胀
· 闲时段与回忆功能共用配置，避免两个重任务功能互相抢资源
