文件夹与存储：虚拟目录 vs 物理空间

相册里的「文件夹」是 Panomint 自己管理的虚拟目录，与磁盘上的物理路径是两套平行世界——理解这一点，扫描导入、权限与整理就都顺了。

创建与选择目录

  1. 进入「文件夹」页，左树选择或右键新建目录；目录名支持中文与多级嵌套。
  2. 选中目录后右侧网格只显示该目录（含子目录可选）的媒体。
  3. 「上传到此处」按钮会把上传目标锁定为当前目录。
虚拟目录不等于物理路径：把文件从磁盘移动走，虚拟目录里的记录不会自动跟随，需要在「工具箱 → 扫描导入」重新索引。
owner 可以在「管理后台 → 存储」里查看虚拟目录与物理挂载点的映射关系。
DEEP DIVE · 实现层

虚拟目录落库为 folders 表（path 唯一键），媒体行的 folder_path 冗余存储；扫描导入按挂载根 diff 增量入索引。权限沿目录子树继承（grants 表按 path 前缀匹配）——因此移动目录即移动权限边界，rename 是原路径 + 前缀批量更新。
