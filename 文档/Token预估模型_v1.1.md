## 二、矫正系数

**k = 2.3**（实测/预估 = 4651.65 / 2000 ≈ 2.33，取 2.3）

偏差归因（v1.0 低估的三类因素）：
1. **后台 agent 自验循环开销**：lint→build→test→fix 循环 + 浏览器实测，单组实际消耗为预估 1.5-2×
2. **环境摩擦成本**：safe-delete 拦截 npm install、EPERM 文件锁、dist 构建锁、并发 vite reload 等，每组多消耗 5-15%
3. **跨组协调成本**：契约缺口补齐（folder_path/thumb 端点/CORS）、中间轮询验证未计入 v1.0

## 三、计算方法（v1.1）

```
阶段预估 = Σ(任务基础值) × k × (1 + f)

k = 2.3          矫正系数
f = 0.10         环境摩擦缓冲（本机环境安全组件较多，后续若迁移至服务器开发可降为 0.05）
```

**任务基础值表**（未矫正，单位 token）：

| 任务类型 | 基础值 | 示例 |
|----------|--------|------|
| 简单后端端点（1-3 个） | 200 | 健康检查、单 CRUD |
| 中等任务（服务/页面） | 400 | 时间轴 API、上传页 |
| 复杂集成 | 800 | 360 引擎集成、转码管线 |
| 多组并行协调开销 | +10-15% 阶段总量 | Wave 制主线验证+修复 |
