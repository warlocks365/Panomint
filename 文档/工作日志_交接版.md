## 2. 关键决策记录

| 决策 | 选择 | 原因 |
|------|------|------|
| Redis 替代 | Valkey 8 | RSALv2/SSPL 不兼容商业化（P0 合规） |
| ffmpeg 调用 | 仅 subprocess 封装 | 避免 GPL 传染（不链接 libav*） |
| Docker 环境 | 本机 WSL2 放弃 → Debian 服务器(192.168.1.115) | 本机 WSL2 无法启用（沙箱限制） |
| 后端框架 | gin + zap（用户选定，推翻 chi/slog 推荐） | 用户偏好成熟生态 |
| 迁移工具 | goose + 重建库 + 按文档块拆 + up-only | 活跃维护；回滚走重建策略 |
| JWT | golang-jwt v5 + refresh 轮换+哈希入库+重放检测 | OWASP 推荐；DDL sessions 表原生支持 |
| 缩略图管线 | 队列异步（队列+ffmpeg 封装串联） | 对齐 TDD §4.1 流水线 |
| 前端虚拟滚动 | vue-virtual-scroller（用户选定，推翻自研推荐） | 用户偏好成熟库 |
| 360 集成 | 原型迁移封装 Vue 组件（非 iframe） | 避免二次返工 |
| 坐标转换 | 应用层 WGS-84→GCJ-02（不落库） | DDL §2.5 约束；数据仅存 WGS-84 |
| 收藏模型 | favorites 相册成员（EXISTS 子查询） | DDL 无 is_favorite 字段（勘误待修） |
| schema 管理 | initdb 脚本 → goose 接管 | compose 中 init 挂载已注释 |
| Token 预估 | 矫正系数 k=2.3（实测 4651.65/预估 2000） | 见 `文档/Token预估模型_v1.1.md` |

**文档勘误（建议修云端 DDL 文档）**：①transcode_jobs 前向外键引用 compute_nodes（顺序错误）②media.hash 注释"pHash"实为 sha256 ③缺 is_favorite 字段（收藏模型依赖 favorites 相册）
