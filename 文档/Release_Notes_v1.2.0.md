## 一、更新摘要

v1.2.0 是一次「管理体验 + 转码控制权」的大版本：扫描导入获得目录树粒度、账号获得扫描根分配、转码开关上收为系统级，同时新增应用内操作手册与版本信息卡。

### 1.1 新增

| 模块 | 内容 |
| --- | --- |
| 扫描目录树选择器 | 管理端扫描导入支持目录树懒加载浏览（`GET /admin/fs/tree`）：单层列举、无权限目录锁定态、防路径穿越；硬编码颜色全量改主题变量 |
| 账号扫描根目录分配 | 管理后台按账号指定 `/data/media` 内真实物理子目录为该账号扫描根（迁移 00039，`users.scan_root` 三态语义：NULL 未分配 fail-closed 403 / 空=媒体根 / 子目录）；成员端「工具箱 → 扫描导入」默认目录即分配根，支持自助触发扫描（三端点），后端 os.Stat 强校验 + dirscope 钳制防越权 |
| 设置页版本信息 | 新增「版本信息」卡：当前版本号（GET /version）+ 历史更新说明 |
| 应用内操作手册 | 设置页入口，使用方法/原理深入两级内容，随版本维护 |
| CI 基线修复 | frontend_org_guard 跨平台基线键缺陷修复（Windows 反斜杠键 vs POSIX 斜杠键），CI quality-gates 恢复绿 |

### 1.2 变更与修复

| 项 | 说明 |
| --- | --- |
| 自动转码开关上收系统级 | 用户级自动 HLS 转码开关上收为系统级（管理后台「转码」页签）；关闭后新视频以原始文件播放（缩略图/索引照常），避免大视频占满服务器 |
| 存储位置死功能移除 | 证据链实证「写入 0 消费/线上 0 行」后整体移除（500 行清理 + 迁移 00035 + 守卫成对删除）；挂载导入落点语义化为 landing_dir（注册即可见 + 扫描可及两条件） |
| Normalize 洗 nil | keep-on-absent 语义在部分更新时失效的缺陷修复（部署验证 8/11 逮住） |

## 三、升级注意事项

1. **含数据库迁移**（00035/00039）：首启 api 容器自动执行（goose up 幂等），升级前建议照常执行 mediadata 卷备份。
2. 若此前使用过用户级自动转码开关，升级后请到管理后台「转码」页签确认系统级开关状态（默认保持历史行为）。
3. 成员账号默认「未分配扫描根」（扫描被 403 拒绝属预期）；需要成员自助扫描时，由管理员在用户页签分配扫描根。
