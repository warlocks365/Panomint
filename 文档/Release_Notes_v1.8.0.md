## 一、更新摘要

### 1.1 任务系统增强（Job000133）

- **扫描任务控制**：管理后台「任务」页可对进行中的扫描任务执行**暂停 / 恢复 / 取消**——暂停保留进度（恢复时按路径预检从断点续跑，绝不重复入库）；取消为终态；
- **结果统计**：已完成/中断的任务显示「新增 N · 重复 N · 失败 N」统计；
- **扫描防重入**：管理面板与工具箱的扫描入口在**有进行中任务时自动显示进度**而非扫描按钮（切换页面返回同样正确恢复），杜绝重复扫描任务；
- 正在处理的文件名实时显示（Job000132 延续）。

### 1.2 播放器增强（Job000135）

- **全屏 / 退出全屏**：播放窗口**左上角**浮动按钮，照片与视频（含 360° 全景）均可用；
- **信息栏一键分享**：照片/视频详情栏新增分享按钮，直接打开创建分享对话框。

### 1.3 分享体系（Job000134）

- **「我的分享」页**（工具箱新增页签）：查看全部分享的链接 / 类型 / **观看次数** / 有效期 / 状态，支持**复制链接 / 查看二维码 / 吊销**；
- **观看记录**：每条分享可展开查看**最近 50 条访问记录（IP / 时间 / UA）**（数据源为既有访问审计，本次新增查询端点与展示）；
- **分享方式**：复制链接 / 二维码（扫码打开）/ 微信内打开自动呈现卡片式排版（方案 A，无公众号依赖；JS-SDK 真卡片分享待公众号资源就绪后另行排期）；
- **入口覆盖**：时间轴批量分享（已有）/ 播放器信息栏（本版新增）/ 相册域（已有）——时间轴、地图、人物、地点、标签内的媒体点开即用播放器分享入口。

## 二、部署指引

```bash
docker pull warlocks/panomint-app:1.8.0
docker pull warlocks/panomint-worker:1.8.0
docker pull warlocks/panomint-web:1.8.0
```

- 迁移 00045 自动执行（仅加四列）；回滚换回 `1.7.3` 重建即可；
- 低配设备延续建议：index-worker 环境变量 `INDEX_THUMB_FAST=1`。
