VIEW.33 · 去除重叠线（需求 F-7）· 同向重复合并 与 近似重合合并
DEDUPE

自动去除重叠线

规则 E1（同向重复合并）+ 规则 E2（近似重合合并）
原始段未去重5 条弧
「南京 → 镇江」走了 3 次、回程 2 次——逐段绘制会得到 5 条弧，其中 3 条下弧完全重合、2 条上弧完全重合。
规则 E1 后同向合并2 条弧
同一有向路径（起点→终点都相同）只保留一条，次数累加为 trips：去程 3 次、回程 2 次 → 线宽与深度随之递增。
规则 E2近似重合再合并
上午与下午两次到访同地被切成两个停留点（相距 < 8px）——它们各自到镇江的弧线几乎叠在一起，按屏幕距离判据合并。
为什么反向段不合并：方向规则下「南京→镇江」画下弧、「镇江→南京」画上弧，二者本来就是上下分离的一对（构成梭形），不构成重叠，因此保留两条——这正是「一去一回」关系的视觉表达。
去重键（E1）= 有向对（起点身份, 终点身份）；trips = 该有向对出现次数
合并键（E2）= 两条弧的 起点屏幕距离 < 8px 且 终点屏幕距离 < 8px（阈值随缩放自适应）
身份归一 = 停留点坐标四舍五入到网格精度（同一网格 → 同一地点身份）
VIEW.34 · 入场动效分帧（需求 F-5）· 弧线沿路径「生长」
MOTION · GROW-IN

动效分帧

单条 0.95s · 按时间顺序错峰 70ms · 缓动 cubic-bezier(.32,.72,0,1)
t = 0.10 s10%
t = 0.35 s35%
t = 0.70 s70%
t = 1.05 s100%
实现选型（三层动效）：① 入场生长——用路径虚线偏移推进（stroke-dasharray / stroke-dashoffset），在真实产品中走 MapLibre 的 line-progress（source 需开 lineMetrics），本原型用等价方式在 SVG 上演示；② 常驻微动效——沿弧缓慢流动的柔和光带（虚线相位），段数超限自动降级为静态；③ 交互反馈——悬停加粗提亮 + 卡片、其余弧降至 35% 不透明度形成聚焦。
prefers-reduced-motion 下三层全部关闭，弧线直接静态呈现。

VIEW.36 · 状态与边界 · 空态 / 单点 / 抽样截断
STATES

状态与边界

三种非正常状态的表现与文案
空态stop_count = 0
提示条居中淡入，2.5 秒自动消失，开关保持开启（不清空用户意图）。
单点stop_count = 1
只有一个地点时无法连线，只显示停留点标记，并说明成因（比「无数据」更准确）。
抽样截断truncated = true
数据超上限时按时间等距抽样（而非取前 N 条），右上角常驻提示，避免「只看到最早几年」的错觉。
抽样为何必须等距：若简单取前 N 条，用户看到的是「只有最早那段历史」的假象，比数据不全更有害。等距抽样保证时间分布均匀，并如实标注已抽样。
VIEW.37 · 移动端窄屏（375 px）
MOBILE

移动端

顶栏图标化 · 时间轴可折叠 · 弧线密度自适应
窄屏适配三条：
① 顶栏按钮文案隐藏、只留图标（沿用既有移动端规则）；计数文字隐藏以让位。
② 时间轴默认折叠为一行（≤40 px），把高度让给地图；足迹仍按当前选定范围生成。
③ 窄屏下地图可视范围变小，停留点自动减少（同一缩放级别下经纬度跨度更窄），弧线密度自然下降——无需额外的移动端专用规则。
触摸与命中：14 px 的透明命中层同时服务触摸；卡片宽度自适应屏宽（最大 260 px），靠边自动翻转避免溢出。
