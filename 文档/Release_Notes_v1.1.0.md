## 一、更新摘要

v1.1.0 聚焦媒体入库效率与数据安全：为管理端补上「按目录批量导入」能力，并修复一个复制场景下的数据覆盖缺陷。

### 1.1 新增

| 模块 | 内容 |
| --- | --- |
| 管理端扫描导入 | 管理后台指定服务器上真实存在的目录批量扫描入库，无需逐一上传；支持配置启动时自动扫描（R1-c），服务重启后自动补扫指定目录 |
| 存储页签修复 | 修复管理后台存储页签显示串台问题（v-show 切换残留） |

### 1.2 修复

| 问题 | 说明 |
| --- | --- |
| 复制媒体同源互覆 | 复制出的副本此前与源文件共用同一存储文件名，再次复制时反向覆盖源文件；改为一次性随机前缀命名（与上传入库对齐），复制副本与源彻底隔离 |

### 1.3 质量与稳定性

- 扫描导入四层验收：本机单元测试 + API e2e 10/10 + 启动自扫 e2e 5/5 + UI e2e 14/14 + dev 栈 8/8
- 附 NAS Docker 挂载问题诊断报告与 e2e 测试报告（Job000111/000112，归档于文档）

## 二、部署指引

```bash
docker pull warlocks/panomint-web:1.1.0
docker pull warlocks/panomint-app:1.1.0
# 编排中 image tag 改为 1.1.0 后 up -d
```

镜像 digest（Docker Hub 实测）：web `sha256:dcd7694f…`、app `sha256:31b2244f…`。
运行版本自检：设置页「版本信息」卡或 `curl http://<host>:8088/version`。

---

## 三、升级注意事项

1. 从 1.0.x 升级：拉新镜像重建即可，无迁移、无配置变更。
2. 启动自动扫描为可选配置，默认关闭；开启后请确认扫描目录范围符合预期（仅管理员可配置）。
