## 一、更新摘要

v1.3.0 将转码发起权交给播放现场：观看未转码视频时可即时发起转码，无需等待系统级批处理；同时统一管理概览的中文展示口径。

### 1.1 新增

| 模块 | 内容 |
| --- | --- |
| 播放时自动转码开关 | 播放未转码视频时可即时发起转码任务（API 契约 v1.13）；与系统级「自动 HLS 转码」开关构成 **AND 组合**——两开关同时开启才会在播放时自动发起，任一关闭则不发起 |
| 索引状态中文化 | 管理概览的索引状态显示统一中文化（idle 等状态不再以英文原文裸露） |

### 1.2 修复

| 问题 | 说明 |
| --- | --- |
| PutSystemConfig 布尔写入 | pgx untyped-nil 坑：`COALESCE` 显式 `::boolean` 锚定，修复配置写入的类型不稳问题 |

## 二、部署指引

```bash
docker pull warlocks/panomint-web:1.3.0
docker pull warlocks/panomint-app:1.3.0
# 编排中 image tag 改为 1.3.0 后 up -d
```

镜像 digest（Docker Hub 实测）：web `sha256:1b328ab3…`、app `sha256:e85f10f2…`（1.3.0 发版为三镜像六 tag 双核验）。

---

## 三、升级注意事项

1. 从 1.2.x 升级：拉新镜像重建即可。
2. 播放时转码为「即时发起」，大视频仍占用服务器算力；如需完全省算力，请保持系统级开关关闭（AND 语义下播放页不会发起）。
