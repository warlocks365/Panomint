## 一、更新摘要

### 1.1 发版后自动提示刷新（根治缓存不更新）

- 每次构建向 Service Worker 注入「版本+构建时间戳」——**发版后浏览器在 60 秒内探知新版本**，页面底部弹出「检测到新版本，刷新后生效」提示条；
- 点击「立即刷新」新服务工作者立即接管并自动重载，**从此升级不再依赖手动清除站点数据/硬刷**；
- 细节：防多标签页连锁刷新；SW 接管期间 API 仍走 NetworkOnly（绝不缓存鉴权数据）。

### 1.2 播放器实时码流信息开关

- 播放窗口左上角新增「码率」按钮（全屏按钮右侧），点击展开实时信息卡：
  - **实时码率**——每 2 秒采样视频资源的实际下载速率；
  - **视频码率**——由文件大小÷时长得出的原始码率（链路能力对照基准）；
  - **缓冲余量**——剩余可播放秒数；
  - **规格**——分辨率 · 编码 · 帧率；
- 诊断外网/弱网播放卡顿：实时码率持续低于视频码率即带宽不足，缓冲余量归零即开始卡。

### 1.3 移动端播放器界面紧凑化

- 768px 以下：控件缩小（36→32px）、信息面板抽屉**全宽**铺满并收圆角、内边距收紧、码率卡同步缩小——手机上看视频/照片不再「所有 UI 挤在一起」。

## 二、部署指引

```bash
docker pull warlocks/panomint-web:1.8.1      # 本版仅有 web 镜像变更
# 其余镜像（app/worker/db）与 1.8.0 相同，可按需一并拉齐 tag
```

回滚：换回 `1.8.0` 重建 web 即可。
